# TECH_SALES_ANALYTICS
Project Overview
This project delivers an interactive Power BI sales analytics dashboard designed to analyze technology sales performance, customer trends, and key revenue drivers. Using historical dataset sourced from Kaggle, the report transforms raw transactional data into actionable business insights to support data-driven decision-making.

Key Features & Insights
Revenue & Sales Performance: Tracks total revenue, sales volume, profit margins, and period-over-period growth.

Product & Category Analysis: Identifies top-performing tech products, categories, and inventory turnover trends.

Customer & Regional Insights: Highlights key customer segments, purchasing behavior, and geographical sales distribution.

Performance Indicators (KPIs): Dynamic KPI cards and trend visuals for instant executive decision-making.

Tech Stack & Tools Used
Data Source: [Kaggle Dataset]

Data Transformation & Cleaning: Power Query (handling missing values, data type casting, custom column creation, and data modeling)

Data Analysis & Calculations: DAX (Data Analysis Expressions) for complex dynamic measures, YTD/MTD calculations, and dynamic KPIs

Data Visualization: Power BI Desktop (interactive dashboards, drill-through pages, custom slicers, and bookmarks)

Business Impact
Executive Visibility: Provides leadership with real-time visibility into high-performing regions and underperforming product lines.

Strategic Optimization: Enables sales teams to target high-value customer segments and optimize promotional strategies.

Data-Driven Operations: Streamlines decision-making processes by replacing static manual reporting with automated visual analytics.
